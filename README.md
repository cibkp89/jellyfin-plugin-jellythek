# Jellythek

Jellyfin-Plugin zum Abrufen von MediathekViewWeb-Feeds als .strm-Dateien.

## Installation

1. Jellyfin: **Dashboard → Plugins → Repositories → Hinzufügen**
2. URL: `https://raw.githubusercontent.com/cibkp89/jellyfin-plugin-jellythek/main/manifest.json`
3. **Plugins → Katalog → Jellythek** installieren
4. Jellyfin neu starten

Voraussetzung: Jellyfin 10.11.0 oder höher.
